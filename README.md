A program (`main.py`, Python 3.13) that writes one line of plain text to
`/output/entry.txt`: a review of planet Earth left by an alien tourist.

> The locals go dark for a third of every day and call it 'sleep'. I tried it. 5/5 stars, would power down again.

Run it with `python3 main.py`. The line is at most 200 characters, a
single line, UTF-8, with one clean joke and the punch at the end.
